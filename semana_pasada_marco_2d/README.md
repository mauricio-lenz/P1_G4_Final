# Semana Pasada - Marco 2D

Trabajo del marco 2D de la imagen inicial.

## Contenido

- `analisis_marco.py`: calcula desplazamientos, reacciones, axial, corte y momento.
- `estructura_inicial.png`: geometria inicial, apoyos y cargas.
- `deformada.png`: deformada del marco.
- `diagrama_axial.png`: diagrama de fuerza axial.
- `diagrama_corte.png`: diagrama de corte.
- `diagrama_momento.png`: diagrama de momento.
- `marco_2d.py`: modelo 2D adicional en OpenSeesPy.
- `modelo_2d_minimo.py`: ejemplo minimo de viga 2D.

## Ejecutar

Desde la raiz del repositorio:

```bat
python semana_pasada_marco_2d\analisis_marco.py
```
